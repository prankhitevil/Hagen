Собеседники
В запись попадёт весь звук компьютера: вместе с голосами собеседников — уведомления и музыка. Звук через динамики: без наушников собеседники попадут в запись дважды. Микрофон услышит собеседников из колонок, и в стенограмме появятся «двойники» реплик. Это программно исправляется, но могут быть погрешности. С наушниками, гарнитурой или спикерфоном двойников нет.
ЧЕРНОВИК
Режим правки: Alt+щелчок по слову — реплика разрежется перед ним. Выделите слова мышью и нажмите Alt+↑ или Alt+↓ — они уйдут реплике выше или ниже (начало — вверх, хвост — вниз). Enter — отдать выделенное другому голосу записи. Выделена вся реплика — Alt+↑/↓ отдадут её соседу целиком. Щелчок по имени меняет голос у всей реплики. Двойной щелчок по реплике правит её текст (Enter — сохранить, Escape — отменить). Ctrl+Z — отменить любое из этих действий, можно несколько подряд.

С телефона

Запись с телефона попадает в программу сама: через папку, за которой программа следит, или через страницу в локальной сети. Файл распознаётся и раскладывается по голосам; документ по нему — кнопкой, когда посмотрите стенограмму.

Папки входящих
Папкиновый звуковой или видеофайл берётся в работу ·
Что уже лежало в папке, когда её добавили, не берётся — только то, что появится после. Чем наполнять папку, программе всё равно: LocalSend («Поделиться → LocalSend» на телефоне, на компьютере — папка приёма), Quick Share, «Связь с телефоном» в Windows 11, папка облачного диска, куда пишет диктофон телефона, или папка загрузок Telegram Desktop — файл, отправленный себе в «Избранное», окажется в ней сам. Файл берётся, когда дописан; оригинал остаётся на месте.
Страница в локальной сети
Страница слушает свой порт и умеет одно — принять файл; стенограммы и настройки через неё недоступны. Открывается только по ссылке с ключом — QR-код и есть эта ссылка; «Новый ключ» делает старую недействительной. При первом включении Windows может спросить, разрешить ли программе принимать подключения, — нужно разрешить для частных сетей. Если телефон страницу не открывает: проверьте, что оба в одной сети (на рабочем Wi-Fi устройства часто разведены), что выбран адрес Wi-Fi, а не адрес VPN, и что брандмауэр или антивирус пропускает порт.

Вид документа
Сеть для Claude CLI
Claude CLI ходит к серверам Anthropic, а те отказывают запросам из части стран. Запрос с «не того» адреса всё равно уносит токен вашего аккаунта и текст стенограммы. Поэтому перед каждым запуском программа решает, каким путём пойдёт CLI, и без уверенности не запускает его.
Как выпускать CLI в сеть
Только через локальный порт VPN-клиента CLI идёт через порт Hiddify, Happ, v2rayN или Nekoray на этом компьютере. Порт не слушает — VPN выключен — CLI не запускается, наружу ничего не уходит.
Как есть, но сначала спросить Anthropic Перед каждым запуском — короткий запрос без токена: пускают ли с нынешнего адреса. Отказ — CLI не запускается. Годится для VPN-туннеля без локального порта.
Без защиты CLI запускается всегда. Если VPN выключен, запрос уйдёт с вашего настоящего адреса вместе с токеном и стенограммой.
Известные порты сейчас
Как это работает. «Проверить выход в сеть» показывает, с какого адреса и из какой страны уходят запросы, и пускает ли с него Anthropic. Токен в проверке не участвует: на той стороне виден только адрес. Кнопка «Проверить» в настройках делает настоящий запрос к модели и подчиняется тем же правилам. Если VPN включён, а порт «не слушает», проверьте в клиенте номер порта и что он не «только для выбранных приложений». Автообновление и телеметрию CLI программа отключает всегда: единственный его выход в сеть — сам запрос к модели.
