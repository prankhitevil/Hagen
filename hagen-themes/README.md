# hagen-themes — что здесь лежит

Пакет тем для «Hagen». Внедряет агент разработки по чек-листу; ничего в
`C:\Users\<пользователь>\Apps\hagen` из этой папки само не копируется.

## Файлы к внедрению (в `static\`)

| Файл | Что делает |
|---|---|
| `themes.css` | токены четырёх тем и четырёх плотностей. Подключать **перед** `app.css` |
| `app.css` | прежний файл, переписанный на переменные: своих цветов в правилах нет |
| `icons.svg` | спрайт иконок интерфейса вместо эмодзи, `currentColor`, ничего из интернета |
| `app-icon-a.svg` / `-b.svg` / `-c.svg` | три варианта иконки приложения — выберите один, из него делается `.ico` |

`preview.css` — только для превью, в программу не идёт.

## Документы

| Файл | Пункт задания |
|---|---|
| `01-colors.md` | таблица цветов по темам + карта замен 32 хардкод-цветов |
| `03-markup.md` | точный список правок разметки, иконки, три коротких патча `app.js`, разметка переключателя тем |
| `05-checklist.md` | чек-лист приёмки (28 пунктов) |
| `06-copy.md` | отдельные предложения по подписям — применять по желанию |
| `Hagen — темы.dc.html` | превью: четыре темы, девять экранов, четыре плотности, кнопки и состояния |

## Рамки, которые соблюдены

- Движок Edge (WebView2), окно от 900×600 — проверено на 900 px.
- Без фреймворков, без загрузки шрифтов и иконок из интернета: `Segoe UI` и
  `Cascadia Mono` / `Consolas` — системные; иконки — локальный SVG.
- Идентификаторы элементов не изменены. Подписи не переписаны (предложения — в `06-copy.md`).
- Функции не убраны: ни одна кнопка не исчезла, «Старт» и «Стоп» остались двумя
  кнопками с теми же id, просто на экране показывается работающая.
- `settings.json` не трогали. Переключатель темы в настройках — разметка и вид готовы,
  проводка за вами (`03-markup.md` §3.6).

## Как устроены темы

`data-theme` на `<html>`: `light` (по умолчанию), `dark`, `warm`, `bright`.
`data-density`: `tiny`, `compact`, `normal` (по умолчанию), `large` — отдельный переключатель,
как вы просили: только шрифты, кнопки и отступы, цвета не меняются.

Смысл цветов одинаков всюду: красный — идёт запись, янтарный — вопрос, зелёный — готово.
Красный разделён на `--rec` (фон кнопки) и `--rec-ink` (красный текст) — без этого
в тёмных темах один и тот же красный не может быть контрастным в обеих ролях.
Так же зелёный: `--ok` и `--ok-ink`.
