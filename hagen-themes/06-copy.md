# 6. Предложения по подписям (не применять молча)

Это список отдельно от правок оформления: каждый пункт меняет текст, который человек читает,
поэтому решение — ваше. Ничего из этого в `app.css` и `themes.css` не зашито.

## 6.1. Кнопки

| Сейчас | Предложение | Зачем |
|---|---|---|
| `+ Новая заметка` | `Новая заметка` (плюс — иконкой) | плюс в тексте дублирует иконку |
| `● Старт` | `Старт` (точка — иконкой `#ic-dot-rec`) | то же |
| `■ Стоп` | `Стоп` | то же |
| `📋 Копировать` | `Копировать` + иконка | то же |
| `+ новая` / `− убрать` (категории) | `Новая категория` / `Убрать категорию` | сейчас непонятно, что именно добавится; в узком окне подписи стоят рядом с «Сохранить стенограмму» и читаются как действия над стенограммой |
| `Свернуть` (две разные кнопки: стенограмма и документ) | `Свернуть стенограмму` / `Свернуть документ` | на экране одновременно две кнопки «Свернуть» |
| `Копировать` (у документа) | `Копировать документ` | там же рядом «Копировать» для стенограммы |
| `🔍 Перечитать точнее` | оставить | точная и живая формулировка |
| `Удалить` | оставить, но окно уже спрашивает объём — это правильно | — |
| `▶ Обработать` | `Обработать файлы` (в «Файлах с диска») | на экране SharePoint рядом есть «Обработать выбранные» |

## 6.2. Состояния и пилюли

| Сейчас | Предложение | Зачем |
|---|---|---|
| `✓ говорящие` | `говорящие размечены` в карточке записи оставить коротким `говорящие ✓` | галочка после слова читается как результат, а не как команда |
| `остановлено` | `запись прервана` | «остановлено» не говорит, есть ли текст |
| `обработка` | `обрабатываю` | рядом уже «размечаю» — единая манера от первого лица |
| `авторазметка ✓` | `размечу сама после «Стоп»` (когда включено) / `авторазметка выключена` | сейчас галочка не объясняет, что будет |
| `модель загружается…` | `загружаю модель распознавания…` | в боковой панели непонятно, какая модель |
| `говорящие размечены` (бейдж у заголовка) | оставить | — |

## 6.3. Пояснения

| Место | Сейчас | Предложение |
|---|---|---|
| `#far-warning` | `⚠ В петлю попадает весь звук выбранного устройства: вместе с голосами запишутся уведомления и музыка.` | оставить, это хороший текст; иконку вынести в `#ic-warn` |
| Пустой экран | `Hagen совещаний` + `Нажмите + Новая заметка…` | заголовок `Готов к записи` (как во втором варианте пустого состояния) — чтобы два пустых экрана не назывались по-разному |
| `#speaker-current` | «00:39 · фраза» | добавить, сколько реплик у этого голоса: человеку легче решить, кто это |
| Конфликт имён | `В этой записи «Имя» уже стоит у другого голоса` | добавить время первой реплики прежнего голоса — сейчас непонятно, о ком речь |
| Вкладка «Вид» | — | подпись под переключателем: `Меняются шрифты, кнопки и отступы. Цвета и функции — нет.` |
| Тёмная тема в списке | — | не называть «Ночная»: программа работает и днём в тёмной |

## 6.4. Названия тем

В переключателе предлагаю ровно эти четыре слова — короткие, без метафор:
**Светлая · Тёмная · Тёплая · Яркая**.

Если захочется различать сильнее: `Тёплая` → `Бумага`, `Яркая` → `Контрастная`.
Оба варианта честнее, чем «Ночь» и «Неон»: первая не про время суток,
вторая — намеренно умеренная.
