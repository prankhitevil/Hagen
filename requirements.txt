# 1. torch ставится ТОЛЬКО с индекса CPU-сборок, иначе подтянется вариант с
#    CUDA на несколько гигабайт, а видеокарты NVIDIA здесь всё равно нет:
#       pip install torch==2.14.0 torchaudio==2.11.0 \
#           --index-url https://download.pytorch.org/whl/cpu
#
# 2. gigaam ставится ИЗ GITHUB, не с PyPI. На PyPI лежит версия 0.1.0, где
#    моделей v3 вообще нет (только v1/v2), и она жёстко требует torch<=2.5.1.
#    Нужные нам v3_e2e_ctc и v3_e2e_rnnt есть только в репозитории. В выпуск
#    едет готовая сборка того коммита, что стоит в .venv (vendor/): так у
#    человека не должен стоять git.
